# Example: RAG Evaluation Direction

```text
Use shushu-novelty-finder.

Direction:
I want to find research novelty around RAG evaluation.

Context:
- field: NLP / IR / LLM systems
- goal: paper-oriented project or strong open-source benchmark
- time: 2-3 months
- compute: limited
- preferred novelty: medium-risk

Please do not search too broadly. First lock the scope. If the direction is still too broad, ask me clarifying questions.

Expected output:
1. Research Scope Card
2. Venue cluster selection
3. Representative papers from the last 10 years
4. Trend Matrix
5. Gap Audit
6. Weak / Medium / Strong novelty ideas
7. Minimum experiments and failure risks
```

## What a good run should avoid

- It should not treat all RAG papers as evaluation papers.
- It should separate retrieval evaluation, generation faithfulness, citation accuracy, robustness, long-context comparison, and production metrics.
- It should distinguish NLP papers, IR papers, benchmark papers, and system papers.
