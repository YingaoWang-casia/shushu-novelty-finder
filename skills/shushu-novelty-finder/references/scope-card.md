# Scope Cards

Use scope cards to prevent vague novelty generation.

## Research Scope Card

```text
Research direction:
CS subfield:
Task:
Input:
Output:
Target users or scenario:
Datasets likely involved:
Metrics likely involved:
Target venue or level:
Resource constraints:
Included directions:
Excluded directions:
Search keywords:
Assumptions:
```

## Seed Paper Card

```text
Title:
Year:
Venue or source:
Paper type: method / benchmark / dataset / survey / system / application
Task:
Input:
Output:
Main method:
Datasets:
Metrics:
Claimed contribution:
Stated limitations:
Future work:
Code or data availability:
Likely research line:
Expansion keywords:
Excluded directions:
```

## Quality check

Before moving to literature search, verify that task, input, output, and metrics are clear enough. If not, ask the user for clarification.
