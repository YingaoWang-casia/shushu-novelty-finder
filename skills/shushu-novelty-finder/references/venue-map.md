## Rule of use

When the user gives a direction, choose 2-4 likely venue clusters. Do not search all CS venues. If the field is ambiguous, ask the user which cluster is intended.

When citing trends, separate:

- accepted main-track papers;
- findings, workshop, or short papers;
- preprints;
- surveys;
- datasets or benchmark papers;
- engineering repositories.
