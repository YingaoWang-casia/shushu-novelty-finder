# Paper Readiness

Use this checklist before calling an idea paper-ready.

## Readiness Card

```text
Paper type:
Core claim:
Main result:
Strong baselines:
Ablations:
Robustness test:
Error analysis:
Qualitative examples:
Efficiency analysis if relevant:
Human evaluation if relevant:
Limitations:
Reproducibility assets:
```

## Verdicts

Use one of these verdicts:

- not ready: no clear claim or evidence;
- pilot-ready: good enough for first experiments;
- workshop-ready: useful but limited;
- main-track candidate: claim, baselines, experiments, and story are feasible;
- technical-report-only: useful artifact but weak research novelty.

## Minimum expectations

A method idea needs strong baselines, simple baselines, ablations, robustness checks, and error analysis.

A benchmark idea needs motivation, construction protocol, quality control, baseline model suite, and evidence that existing evaluation misses something important.

A dataset idea needs collection protocol, labeling rules, statistics, bias analysis, baseline tasks, and ethical checks.

A system idea needs architecture, constraints, latency, throughput, cost, reliability, stress tests, and failure analysis.

An analysis idea needs controlled experiments, alternative explanations, cross-model or cross-dataset validation, and implications.
