# Output Checklist

Use this checklist after a Skill run.

## Scope

- [ ] The output identifies Direction Mode, Seed Paper Mode, or Hybrid Mode.
- [ ] The output states assumptions if the user did not provide enough detail.
- [ ] The task, input, output, dataset, and metric are clear enough.

## Literature

- [ ] The output lists representative papers with title, year, venue/source, and relevance.
- [ ] It separates accepted papers, preprints, surveys, benchmark papers, and engineering artifacts.
- [ ] It does not use one paper to support a field-wide claim.

## Gap audit

- [ ] Each gap has a gap type.
- [ ] Each gap has an evidence label.
- [ ] Inferred gaps are marked as hypotheses.

## Novelty

- [ ] Ideas are separated into weak, medium, and strong.
- [ ] Each idea includes evidence, risk, feasibility, and minimum experiment.
- [ ] The best 1-3 ideas are recommended with reasons.

## Paper readiness

- [ ] Medium and strong ideas include a paper thesis if Paper Mode is requested.
- [ ] Baselines and ablations are specified.
- [ ] Threats to validity are listed.
- [ ] The paper-readiness verdict is explicit.
